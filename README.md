# vibedrive-site

Public-facing site for VibeDrive at <https://vibedrive.app>.

Hosts the Privacy Policy, Terms & Conditions, and account-deletion instructions for the VibeDrive Android app (Play Store package `com.drivex.vibedrive`).

## Pages

- `/` — homepage
- `/privacy/` — Privacy Policy
- `/terms/` — Terms & Conditions
- `/account-deletion/` — account deletion instructions

## Local preview (optional)

```bash
bundle install
bundle exec jekyll serve
```

Then open <http://127.0.0.1:4000>.
